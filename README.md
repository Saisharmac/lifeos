# Mr.Shadow v20 — Aurora-9 Visual Edition

Appearance-only redesign of the Mr.Shadow personal PWA. The update keeps the existing app logic and local data identifiers while refining lighting, surfaces, navigation, typography, touch feedback, responsive layout, and the app icon.

## Deploy to GitHub Pages
1. Export a JSON backup from your current app.
2. Extract this folder.
3. Replace `index.html`, `manifest.webmanifest`, `sw.js`, and `icon.svg` in the root of your existing `lifeos` repository.
4. Commit and wait for GitHub Pages to publish.
5. Reopen the app and visually check Today, Tasks, Toggl, Habits, a modal and Settings on your phone.

No external dependencies or paid services are required. The app remains local-first.
